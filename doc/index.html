Расширение для управления пассажирскими маршрутами | Аналог системы «Трансфлоу» | PILOT Extensions
✅ Статус: Рабочий MVP. Готов к деплою на Cloudflare / GitHub Pages / AWS EC2.

📋 Описание

Расширение passenger_transit интегрируется в интерфейс PILOT и предоставляет функционал диспетчерской системы для управления пассажирскими перевозками. Модуль использует нативную карту PILOT (Leaflet), деревья объектов и API мониторинга, создавая бесшовный опыт работы в едином интерфейсе.

🚀 Установка

Вариант 1: Cloudflare Pages (рекомендуется для статики)

  1. Откройте Cloudflare Dashboard → Workers & Pages
  2. Создайте приложение → Pages → Upload assets
  3. Загрузите ZIP-архив со всеми файлами расширения
  4. Получите URL: https://passenger-transit.YOUR.workers.dev/
  5. В PILOT: Администрирование → Приложения → Добавить
    • Имя: passenger_transit (строго snake_case!)
    • URL: https://passenger-transit.YOUR.workers.dev/
  6. Сохраните, включите для пользователя, перезагрузите PILOT (F5)

Вариант 2: AWS EC2 + Nginx + PHP-FPM (для бэкенда)

  1. Установите Nginx + PHP-FPM: 
    sudo dnf install -y nginx php-fpm php-pdo php-sqlite3
  2. Разместите файлы: /var/www/pilot_extensions/passenger_transit/
  3. Настройте Nginx (см. DEPLOY.md в репозитории PILOT Extensions)
  4. В PILOT зарегистрируйте: https://ext.example.com/passenger_transit/

Вариант 3: GitHub Pages (только статика)

  1. Создайте репозиторий на GitHub
  2. Загрузите файлы в корень
  3. Settings → Pages → Source: main branch
  4. URL: https://USERNAME.github.io/REPOSITORY/
  5. В PILOT: зарегистрируйте этот URL
⚠️ Важно: GitHub Pages не поддерживает PHP — бэкенд не будет работать. Для полноценной функциональности используйте Cloudflare Workers или AWS EC2.

📖 Использование

Создание маршрута

  1. В левой панели нажмите «Добавить маршрут»
  2. Введите название маршрута
  3. Выберите маршрут в дереве
  4. Нажмите «Рисовать маршрут» (прямое или обратное направление)
  5. Кликайте по карте для добавления точек маршрута
  6. Правый клик или «Завершить» — сохранить полилинию

Добавление остановок

  1. Выберите маршрут в дереве слева
  2. Нажмите кнопку «Редактировать» (режим остановок)
  3. Кликните по карте в месте остановки
  4. Введите название остановки

Привязка ТС

  1. Выберите маршрут в дереве
  2. Нажмите «Привязать ТС»
  3. В открывшемся окне выберите ТС из списка (загружается из PILOT)
  4. Нажмите «Привязать»

Просмотр трека ТС

  1. Кликните по маркеру ТС на карте
  2. Система загрузит трек из PILOT API (/ax/rep.php)
  3. Отобразится трек с выделением прямого/обратного направления
  4. Покажется количество выполненных рейсов

Мнемосхема маршрута

Правая панель отображает нитку графика маршрута. Остановки пронумерованы. Клик по остановке на карте подсвечивает её в мнемосхеме. Переключайтесь между прямым и обратным направлением кнопками вверху панели.

🗄️ Структура базы данных (SQLite)

Таблица Назначение Ключевые поля
routes Список маршрутов id, name, created_at
stops Остановки маршрута id, route_id, name, lat, lon, order_index
route_points Точки полилинии маршрута id, route_id, direction, lat, lon, order_index
route_vehicles Привязка ТС к маршрутам id, route_id, vehicle_id, vehicle_number
💡 Примечание: База данных SQLite создается автоматически при первом запуске API. Файл data.db размещается в папке backend/.

🔌 API эндпоинты

Все запросы идут через прокси PILOT: /store/passenger_transit/backend/api.php

Метод Action Описание Параметры
GET get_routes Список маршрутов —
POST create_route Создать маршрут name
POST add_stop Добавить остановку route_id, stop
POST save_route_points Сохранить точки полилинии route_id, direction, points
GET get_route_vehicles ТС маршрута route_id
POST bind_vehicle Привязать ТС route_id, vehicle_id, vehicle_number
POST unbind_vehicle Отвязать ТС route_id, vehicle_id
GET get_vehicle_track Трек ТС vehicle_id, route_id, date
GET get_timeline Таймлайн рейсов route_id, date
🔗 Интеграция с PILOT API: Для получения реальных координат ТС и треков используются:
  • /ax/tree.php — список ТС с позициями
  • /ax/rep.php?cmd=get_trips — треки и рейсы
Все запросы к PILOT API идут с того же домена, CORS не возникает.

⚙️ Требования

  • PILOT с поддержкой расширений
  • Ext JS 7.7+ (загружен PILOT)
  • Leaflet (используется PILOT MapContainer)
  • Highcharts (опционально, для таймлайна)
  • PHP 7.4+ с PDO SQLite (для бэкенда)

🔧 Технические детали

Расширение следует строгому контракту AI_SPECS.md репозитория PILOT Extensions:

  • Не является standalone SPA
  • Точка входа — Module.js
  • Имя расширения: passenger_transit (snake_case, без дефисов)
  • Класс: Store.passenger_transit.Module
  • Интеграция через window.skeleton
  • Карта — Leaflet через mapContainer.map
  • Все URL проксируются через /store/passenger_transit/...

🐛 Troubleshooting

Модуль не появляется в PILOT

  • Проверьте, что Module.js открывается в браузере по прямому URL
  • Убедитесь, что имя расширения — passenger_transit (snake_case, без дефисов!)
  • Проверьте консоль браузера на наличие ошибок
  • Перезагрузите PILOT (F5)

CSS не загружается

  • Проверьте, что style.css открывается по прямому URL
  • Убедитесь, что путь в Module.js корректный

Бэкенд не работает

  • Проверьте права на запись в папку backend/ (для создания data.db)
  • Убедитесь, что PHP-FPM запущен и настроен
  • Проверьте логи Nginx: /var/log/nginx/error.log

Карта не отображается

  • Убедитесь, что вы находитесь в разделе Online или History PILOT
  • Проверьте, что getActiveTabMapContainer() доступен
  • Откройте консоль браузера и проверьте ошибки Leaflet
